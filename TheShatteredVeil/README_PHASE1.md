# The Shattered Veil — Fresh Rebuild

The previous procedural character has been abandoned. It is not used as a base.

Development now follows gated phases. A later phase does not begin until the current phase is visually approved.

## Active phase

**Phase 1 — Body proportions and anatomy**

This build contains only:

- Custom torso and pelvis masses
- Stylized shoulders, arms, elbows and forearms
- Palms, thumbs and four readable fingers per hand
- Thighs, knees, calves and ankles
- Shaped feet
- A temporary head mass used only to judge total proportions
- Neutral gray materials and neutral white lighting

It intentionally does not contain hair, clothing, blindfolds, swords, VFX or cinematic presentation.

## Run

From the repository root:

```powershell
git pull
.\build-character.bat
```
