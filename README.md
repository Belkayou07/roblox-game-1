# Roblox Game 1

Minimal Roblox and Rojo project.

## Current scene

The server creates only:

- one spawn position
- one visible start line
- one straight path

The path is 60 studs wide and 2,000 studs long.

## Run

```powershell
rokit install
rojo serve
```

Connect the Rojo plugin in Roblox Studio, then press **Play**.
